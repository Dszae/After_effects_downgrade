# Security Policy

## Reporting Security Issues

If you discover a security vulnerability or potential data-safety issue, please report it responsibly by opening a GitHub issue or contacting the maintainer directly.

---

## Privacy & Data Handling Guarantee

- **Zero Remote Transmission:** All file processing (both in the browser via Web APIs / TypedArrays and in the Python CLI) occurs strictly in local workstation memory.
- **No Telemetry or Analytics:** This repository contains no analytics scripts, cookies, external tracking pixels, or remote telemetry.
- **Standalone Offline Execution:** The web application requires no active internet connection and runs completely offline when opened via `index.html` or `python server.py`.
